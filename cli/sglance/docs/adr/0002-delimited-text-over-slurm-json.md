# Parse delimited text instead of Slurm JSON

Slurm added `--json` in 21.08, which makes `json.loads` look like the straightforward parser choice for a Python CLI. `sglance` instead parses pipe-delimited text from `sinfo -h -N -O`, `squeue -h -r -O`, and `sacct -X -P -n`, using `-O` with `:0|` no-truncation field specifiers rather than `-o` because `-O` exposes extended fields such as `squeue`'s `tres-alloc` and `sinfo`'s `GresUsed` that single-letter `-o` specifiers lack, while older or minimal Slurm builds omit the `serializer/json` plugin and `--json` OpenAPI schemas rename and retype fields across Slurm 22.05 through 24.11. We accept custom string splitting and GRES and TRES token parsing so one parser works across heterogeneous Slurm versions without per-release schema branches.
