# Restrict execution to a fixed allowlist of read-only Slurm commands

Competing Slurm TUIs bundle job cancellation, holds, and `sbatch --test-only` start-time probes, and sibling SSH tools allow custom remote command strings in configuration. `sglance` restricts every remote and local execution to a hardcoded allowlist of `sinfo`, `squeue`, `sacct`, and `scontrol show config` with a single leading `env SLURM_TIME_FORMAT=%s` prefix, providing no configuration hook to override the remote binary and no `sbatch --test-only` code path. This sacrifices prospective wait-time probes for unsubmitted jobs and custom wrapper scripts, so unattended AI agents can invoke `sglance` freely without submission guardrails, `job_submit` plugin side effects, or command-injection risk from configuration files.
